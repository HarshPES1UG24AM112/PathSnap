# Data

Place the supplied dataset here (git-ignored):

```
data/raw/train/<trip_id>/<trip_id>.{track,nodes,arcs,route}          (80 trips)
data/raw/student_test/<trip_id>/<trip_id>.{track,nodes,arcs,route}   (10 trips)
```

`data/processed/` is generated by `python scripts/02_build_dataset.py`.
Evaluator-testing trips are not stored in the repository; the API reads them from `PATHSNAP_EVAL_DIR` on Laptop 1.
